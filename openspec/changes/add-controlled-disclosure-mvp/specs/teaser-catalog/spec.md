# Delta for teaser-catalog

## ADDED Requirements

### Requirement: Публичный каталог teaser-карточек
Система SHALL предоставлять анонимному посетителю список карточек в статусе `published`, содержащий только teaser-поля:
`id`, `title_generic`, `industry`, `region_macro`, `size_band`, `revenue_band`, `deal_type`, `teaser_text`, `published_at`.
Confidential-поля (`org_name`, `org_aliases`, `full_description`, материалы) MUST NOT присутствовать ни в одном публичном ответе.

#### Scenario: Анонимный просмотр каталога
- **GIVEN** в каталоге есть опубликованные и черновые карточки
- **WHEN** анонимный посетитель вызывает `GET /api/v1/cards?page=1`
- **THEN** ответ 200 содержит только опубликованные карточки и только teaser-поля

#### Scenario: Confidential-поля не утекают (TC-CAT-01)
- **WHEN** выполняется любой публичный запрос каталога или карточки
- **THEN** в теле ответа отсутствуют ключи и значения `org_name`, `org_aliases`, `full_description`, `storage_key`

### Requirement: Просмотр одной teaser-карточки
Система SHALL отдавать одну опубликованную карточку по `GET /api/v1/cards/{id}`, где `id` — UUIDv4.
Для несуществующей, черновой или архивной карточки система MUST возвращать одинаковый ответ 404.

#### Scenario: Черновик недоступен публично (TC-CAT-02)
- **GIVEN** карточка в статусе `draft`
- **WHEN** анонимный посетитель запрашивает её по UUID
- **THEN** ответ 404 с тем же телом, что и для случайного UUID

### Requirement: Непрогнозируемые идентификаторы и защита от перебора
Публичные ID карточек SHALL быть UUIDv4. Каталог MUST поддерживать только постраничную выдачу с размером страницы ≤ 20,
без параметров, позволяющих получить все записи за один запрос. Система MUST применять rate limit к каталогу (см. platform-security).

#### Scenario: Попытка выгрузить всё (TC-CAT-03)
- **WHEN** клиент запрашивает `GET /api/v1/cards?page_size=10000`
- **THEN** ответ 422 либо выдача обрезается до 20 записей

#### Scenario: Скрейпинг упирается в rate limit
- **WHEN** с одного IP отправлено более 60 запросов к каталогу за минуту
- **THEN** последующие запросы получают 429 с заголовком `Retry-After` и событие `catalog.rate_limited` пишется в аудит (агрегированно, не чаще 1 раза в минуту на IP)

#### Scenario: Невалидный ID
- **WHEN** запрошен `GET /api/v1/cards/123`
- **THEN** ответ 404 (не 500 и не стек-трейс)

### Requirement: Фильтрация каталога по обобщённым признакам
Система SHALL позволять фильтровать каталог по `industry`, `region_macro`, `deal_type` (значения enum).
Фильтры MUST NOT позволять комбинацию, сужающую выдачу до признаков, которых нет в teaser (например, по `org_name`).

#### Scenario: Неизвестный фильтр игнорируется
- **WHEN** запрос содержит `?org_name=Acme`
- **THEN** параметр отклоняется (422) и выдача не зависит от confidential-полей
